# Documentation

Claude Code reads these at the start of every session (see /CLAUDE.md), so they
must live here, not only in Claude Docs.

## Export these four into this folder before the first Claude Code session

Open each in Claude and export as Markdown, saving with exactly these names:

| File | Source |
|---|---|
| `product-specification.md` | WorkMate 2.0 — Product Specification |
| `dimension-engine-architecture.md` | Dimension Engine — Technical Architecture |
| `technical-specification.md` | WorkMate 2.0 — Technical Specification for Orchard Core |
| `prompt-library.md` | WorkMate 2.0 — Claude Code Prompt Library |

Also useful but not required by the prompts: the aviation pack requirements
framework, the QuickHCM migration assessment, and the commercial pricing model.

## Folders

- `adr/` — architecture decision records. One file per decision, numbered.
- `modules/` — reserved for cross-module design notes; per-module READMEs live in each module.
